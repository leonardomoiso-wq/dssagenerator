# Caratteri

Basier Circle e Wotfard (Atipo Foundry) sono caratteri commerciali: non sono nel repository.
Copia qui i file con licenza (`.woff2`, `.woff`, `.otf` o `.ttf`). Il nome del file deve contenere
«Basier» o «Wotfard» e il peso (Regular, Medium, SemiBold), per esempio:

| File | Carattere | Peso |
| --- | --- | --- |
| `BasierCircle-Regular.*` | Basier Circle | 400 |
| `BasierCircle-Medium.*` | Basier Circle | 500 |
| `BasierCircle-SemiBold.*` | Basier Circle | 600 |
| `Wotfard-Regular.*` | Wotfard | 400 |
| `Wotfard-Medium.*` | Wotfard | 500 |
| `Wotfard-SemiBold.*` | Wotfard | 600 |

In alternativa si trascinano nel compositore (pannello «Caratteri»): restano salvati nel browser.
Senza i file l'anteprima usa Karla, sostituto documentato per Google Slides (manuale, p. 26-27),
e il compositore lo segnala. Per l'esportazione definitiva servono i caratteri ufficiali.
